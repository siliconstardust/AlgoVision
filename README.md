# AlgoVision — DSA Visualizer

> An interactive web application that makes Data Structures and Algorithms easier to understand through visualizations, animations, and step-by-step execution.

🔗 **Live Demo:** [AlgoVision](https://algo-vision-fawn.vercel.app/)

---

## 📌 Overview

**AlgoVision** is a web-based DSA visualizer designed to help students understand how algorithms work by seeing their execution in real time.

Instead of only studying algorithmic steps theoretically, users can interact with algorithms, observe comparisons and swaps, follow searching operations, and compare different algorithms on the same input.

---

## ✨ Features

### 🔢 Sorting Visualizer

Visualize popular sorting algorithms with animated execution:

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

The visualizer shows the algorithm's progress step-by-step, making it easier to understand how elements are compared, moved, and sorted.

### 🔍 Searching Visualizer

Understand searching algorithms through interactive animations:

* Linear Search
* Binary Search

Users can observe how the algorithm searches through the dataset and identifies the target element.

### ⚔️ Algorithm Battle

Compare two algorithms side-by-side using the same input.

The Algorithm Battle feature helps users understand:

* Execution behavior
* Number of operations
* Relative performance
* Differences between algorithms

### 📊 Complexity Analysis

Each algorithm includes information about:

* Best-case time complexity
* Average-case time complexity
* Worst-case time complexity
* Space complexity
* Algorithm explanation
* Real-world use cases

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/siliconstardust/AlgoVision.git
```

Navigate to the project directory:

```bash
cd AlgoVision
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.
