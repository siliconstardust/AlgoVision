# AlgoVision — DSA Visualizer

A modern, interactive visualizer for Data Structures & Algorithms built with React + Vite + Tailwind CSS.

## Features
- **Sorting Visualizer**: Bubble, Selection, Insertion, Merge, Quick Sort with real-time stats
- **Searching Visualizer**: Linear and Binary Search with step-by-step animation
- **Algorithm Battle**: Compare two algorithms side-by-side on the same input
- **Complexity Panel**: Big-O info, explanations, and real-world use cases

## Getting Started
```bash
npm install
npm run dev
```

## Deploy to Vercel
Push to GitHub, then import in Vercel. Zero config needed — `vercel.json` handles SPA routing.

## Tech Stack
- React 19 + Vite 8
- Tailwind CSS v4
- React Router DOM v7
- No external UI libraries
